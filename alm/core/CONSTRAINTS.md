PHASE 3 — CONSTRAINTS (SEAL)
These constraints override all earlier Phase-3 guidance.

C1 — No Semantics
No symbols, categories, labels, or interpretation.

C2 — No Absolute Values
All meaningful computation must arise from paired deviation.

C3 — No Control
No feedback, no correction, no gating.

C4 — No Synchronization
No locks, no waits, no barriers beyond atomics already present.

C5 — No Cleanup
Do not reset, normalize, or sanitize state.

C6 — No Observer Bias
Metrics may be recorded but never consumed by operators.

C7 — Physics First
If a digital shortcut conflicts with physical plausibility:

choose physical

accept inefficiency

document deviation

C8 — Hardware Adaptivity Allowed
SIMD width detection is allowed.
Behavioral semantics must remain invariant.

C9 — Reversibility Preference
Operators should prefer forms that:

decay naturally

diffuse naturally

do not explode without cause

C10 — Phase Isolation
Phase-3 must remain usable even if:

Phase-4+ never exist

No agent consumes its output

No cognition ever appears

Final Seal
Phase-3 exists to let structure prove it deserves to exist.

If something survives Phase-3:

it earned persistence

it earned propagation

it earned future relevance
