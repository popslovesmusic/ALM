## System Fundamentals
- **Ontological stance:** ALM is a continuous dynamical system; meaning is the persistence of relational patterns, not symbols (`NOT_IS ANALYSIS.md`).
- **Relational semantics:** Lanes encode coupled aspects of a single law, not independent samples. Pairwise symmetry must hold across the 32-lane payload (`SIMD as Ontology.md`).
- **Spiral meaning:** Concepts are spiral trajectories generated by dual-frequency interaction and decay (`The Spiral Concept in ALM.md`).

## Physical Runtime Envelope
- **State geometry:** Active state is a 10×10 grid of cells with four registers (R, G, B, I) per cell, arranged into four AVX2 lane blocks (0–31) (`ALM Lane Map and Coefficient Tables Spec v0.md`).
- **Cache residency:** The four-slice stencil fits within the L2 cache budget; spilling to L3 or DRAM is a violation (`CACHE_RESIDENCY_PROOF.md`).
- **SIMD governance:** Only whitelisted AVX2 intrinsics are allowed; masking, reductions, gathers, shuffles, and branching are prohibited to preserve simultaneity (`AVX2_KERNEL_RULES.md`).

## Time Structure
- **Four-slice stencil:** `FUTURE → NOW → RECENT → STABLE` rotates by pointer/index swap—no copying. Information flows forward only (`TIME_STENCIL_MECHANICS.md`).
- **Cadence:** Each stencil advancement corresponds to exactly one ingest frame; mid-step injection is forbidden (`TOPOLOGY & INGEST CONTRACT.md`).

## Topology and Ingest
- **Neighbor contract:** Every cell has exactly 12 symmetric neighbors with uniform weights; no rewiring, weighting gradients, or per-lane specialization (`TOPOLOGY & INGEST CONTRACT.md`).
- **Closure:** Topology is static for system lifetime; long-range shortcuts and authority gradients are disallowed (`Final Topology Closure.md`).
- **Ingest channels:** External signals enter only via declared ingest lanes, orthogonal to pressure/persistence channels and without control metadata (`INGEST_LANE_BINDING.md`, `TOPOLOGY & INGEST CONTRACT.md`).

## Kernel Law and Coefficients
- **Relational kernel:** State update is residual-based (`Δ* = U* - k*`) with dual-frequency terms (fast angular, slow radial) and skew-symmetric coupling to enforce spin without branching (`Relational Kernel Law Spec v0.md`).
- **Coefficient canonicalization:** Coefficient vectors (`α, β, Γ`) must be symmetric (`q[ℓ̄] = q[ℓ]`), normalized, and mapped exactly to lane blocks; no adaptive or data-dependent tuning is allowed (`COEFFICIENT CANONICALIZATION CONTRACT.md`, `ALM Lane Map and Coefficient Tables Spec v0.md`).
- **Chromatic conservation:** Lane layout preserves 12-hue/12-tone structure with reserved auxiliary lanes for cross-coupling and stability (`Chromatic Structure as Conserved Ontology.md`).
- **Topology coupling:** Neighbor aggregation is uniform; no distance metrics, gating, or implicit control terms (`TOPOLOGY & INGEST CONTRACT.md`).

## Pressure, Focus, and Decay
- **Pressure laws:** External pressure modulates decay rates and coupling magnitude multiplicatively; it never carries control flow (`PRESSURE_AND_DECAY_LAWS.md`).
- **Orthogonality:** Pressure signals are orthogonal to state evolution channels, preventing control leakage or topology distortion (`PRESSURE_SIGNAL_ORTHOGONALITY.md`).
- **Focus transfer:** Focus drift under jitter follows prescribed handoff rules to maintain continuity without branching or masks (`JITTER_FOCUS_TRANSFER.md`).
- **Boundary conditioning:** Boundary responses must use resonant constraints rather than gates or clamping; no thresholding is permitted (`Resonant Semantic Conditioning via Dynamic Boundary Constraints.md`).

## Spiral Semantics and Observability
- **Spiral generation:** Dual-frequency dynamics produce angular motion and radial persistence; long-lived spirals constitute concepts (`The Spiral Concept in ALM.md`).
- **Observation rules:** Observables must be passive and non-invasive; sampling cannot alter stencil rotation, pressure channels, or topology (`SPIRAL_OBSERVABLES.md`).

## Testing and Compliance
- **Invariant regression:** The invariant suite must accompany any implementation to detect violations of kernel, topology, timing, or pressure laws (`docs/tests_and_support/INVARIANT_REGRESSION_TESTS.md`).
- **Checklist:** The blueprint checklist documents readiness gates and must be satisfied before integration (`Blueprint checklist.md`).
- **Scalar equivalence:** Scalar and AVX2 paths must be deterministically equivalent; divergence is a hard failure (`AVX2_KERNEL_RULES.md`).

## Provenance
- **Development record:** `ALM_Creation_Journal.md` retains the detailed rationale and historical derivation of the above rules. It informs traceability but does not override the contracts listed here.

Canonical Execution Language Rule
Canonical ALM execution may be implemented in languages that provide:

explicit memory layout control

deterministic floating-point behavior

enforceable SIMD or vector simultaneity

zero hidden control flow

compile-time or provable runtime invariants

Approved canonical languages (initial):

C++ (primary)

Rust (with explicit SIMD + unsafe where required)

Julia (only with static arrays, no dynamic dispatch, no JIT variance)
