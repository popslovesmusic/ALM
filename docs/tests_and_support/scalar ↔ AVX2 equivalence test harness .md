Below is a scalar ↔ AVX2 equivalence test harness you can drop into your repo as a single test file. It is written to be:

* deterministic (fixed seed)  
* strict about lane pairing and layout assumptions (32 lanes \= 4×8 AVX2 blocks)  
* extensible to time-slices/cells  
* tolerant in a controlled, explicit way (ULP-ish behavior via abs/rel eps)  
* code-only (no governance)

I’m assuming you already have (or will stub) these two entry points:
