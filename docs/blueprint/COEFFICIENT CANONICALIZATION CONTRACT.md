# PART II — COEFFICIENT CANONICALIZATION CONTRACT

ALM Coefficient Canonicalization Contract v1.0 (Proposed Canonical)  
---

## 1\. Purpose

This contract defines the authoritative realization of all ALM kernel coefficients.  
Its role is to ensure:

* Determinism  
* Cross-implementation identity  
* Test reproducibility  
* Cache-proof behavior

---

## 2\. Derived Constraints (Non-Negotiable)

Coefficients must satisfy:

* Mod-12 structure  
* Pairwise symmetry  
* Orthogonality between functional lanes  
* Bounded decay  
* Non-explosive dynamics  
* Pressure invariance

These constraints eliminate empirical tuning.  
---

## 3\. Coefficient Families

ALM coefficients are grouped into:

* α (state interaction coefficients)  
* β (temporal modulation coefficients)  
* Γ (pressure coupling coefficients)

---

## 4\. Generation Rule

Declaration (Constitutional Choice):  
All coefficients are generated by a deterministic rule, not stored as free tables.

### 4.1 Indexing

Coefficients are indexed by:  
scss  
Copy code  
(mod12\_lane\_index, paired\_lane\_index)

---

### 4.2 Symmetry Rule (Derived)

For all coefficients x:  
Copy code  
x\[i, j\] \= x\[j, i\]  
x\[i, j\] \= \-x\[i ⊕ 6, j ⊕ 6\]

(where ⊕ is mod-12 addition)  
---

### 4.3 Normalization Rule (Derived)

Coefficients satisfy:

* Sum-to-zero across paired lanes  
* Bounded L2 norm ≤ declared constant C  
* Zero net gain over one full cycle

---

### 4.4 Canonical Constant Declaration

Declaration (Explicit Authority):  
The normalization constant C is declared once and is immutable.  
This is a constitutional constant, not a tunable parameter.  
---

## 5\. Forbidden Variability

* No runtime modification  
* No learning  
* No adaptation  
* No environment-dependent scaling

---

## 6\. Validation Requirement

Any implementation must be able to:

* Regenerate coefficients from the rule alone  
* Produce bit-identical tables (within tolerance)  
* Pass all kernel invariance tests without special casing

---

## 7\. Contract Status

This contract is:

* Closed  
* Deterministic  
* Binding across implementations
